# Setup

This is the documentation for LLM chat clients that support **stdio** protocol. For Streamable HTTP refer to the [Llama.cpp](https://projects.blender.org/lab/blender_mcp/wiki/llama.cpp) documentation.

## Install the Add-on and launch Blender

Follow the [instructions](https://blender.org/lab/mcp-server#add-on) on how to install the add-on on Blender 5.1 or newer.

## MCP Server Installation

### Windows

In the powershell run:

```bash
cd c:\
git clone https://projects.blender.org/lab/blender_mcp.git
```

This will download the MCP Server directly in the `C:\` directory. If you want to use a different destination make sure to use that also during the Setup step.

### MacOS / Linux

In the terminal run:

```bash
cd $HOME
git clone  https://projects.blender.org/lab/blender_mcp.git
```

This will download the MCP Server directly in the home directory. If you want to use a different destination make sure to use that also during the Setup step.

## MCP Config File

While most LLM clients may allow you to add a new MCP server via a dialog, under the hood there is a config file. The specifics of the file format depends on your client, so you may need to adjust the following accordingly.

### Windows

```json
{
	"mcpServers": {
		"blender": {
			"command": "uv",
			"args": [\
				"--directory",\
				"C:\\blender_mcp\\mcp",\
				"run",\
				"blender-mcp"\
			]
		}
	}
}
```

### MacOS / Linux

```json
{
	"mcpServers": {
		"blender": {
			"command": "uv",
			"args": [\
				"--directory",\
				"$HOME/blender_mcp/mcp",\
				"run",\
				"blender-mcp"\
			]
		}
	}
}
```

_Note: Some LLM clients may not support local variables ($HOME). In those cases replace them with your local directory (e.g., /home/my-user, /Users/my-user)._
